## How to judge a directory in 90 seconds

1. **Check organic traffic, not domain rating.** A DR 70 site with 200 monthly visitors is a link farm that got good at link building. One Ahrefs or Semrush lookup tells you.
2. **View source on an existing listing.** Search for `rel="nofollow"` or `rel="sponsored"` on the outbound link. If it's there you're getting a mention, not a link — fine if the directory sends traffic, worthless if it doesn't.
3. **Search their listings on Google.** Query `site:directory.com "some listed tool"`. If their listing pages aren't indexed, yours won't be either.
4. **Look at the newest listings.** If the last approved submission was four months ago, the directory is abandoned.
5. **Check whether descriptions are unique.** Scraped meta descriptions across every listing means no human touched it, and Google treats the whole domain accordingly.
6. **Watch for badge requirements.** Several directories only give you the dofollow link once you embed their badge on your site. That's a reciprocal link exchange — fine in moderation, a pattern worth avoiding at scale.

**Column key** — **DR**: Ahrefs Domain Rating. **Link**: dofollow, nofollow, or varies by page. **Cost**: cheapest tier that gets you listed.

## The submission asset pack

Prepare once, reuse everywhere. Most directories ask for the same nine things:

- Product name and a one-line description under 60 characters
- Long description, 300-500 characters, written without marketing filler
- Logo: 512x512 PNG, transparent background
- Screenshot or OG image: 1280x720
- Pricing model: free, freemium or paid, plus the actual entry price
- Category and 5-8 tags
- Founder name and X or LinkedIn profile
- Launch date
- Whether the tool is self-hostable and whether there is a public API
